# dsh-wsl-clipboard

DeepSeek Harness plugin: **read / write the Windows clipboard** from an agent running in WSL.

## Install

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-clipboard
```

Restart `dsh web`. Tool: `wsl_clipboard` (`action: get|set`).

Part of **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**.
